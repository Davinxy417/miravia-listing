# Miravia 西班牙站文案规则

给agent写当前批次content.json和overlays.json用，中文沟通，自然西班牙语商品文案。依据为原图可见、用户确认或核实的同款资料；生成图和旧AI答案不能证明事实。不编材质、尺寸、容量、保温时长、兼容、防水、抗菌、认证或疗效，不借其他商品的规格/联系资料。

## 字段与实际校验

|字段|check/fill限制|写法|
|---|---|---|
|title|55～75字符（含空格）|核心买家搜索词放前48字符，后接核实属性/规格/件数；组合装以Pack de N开头，与pack_qty一致；多规格链接不只写主推规格。|
|description|400～1200字符，HTML标签也计入|尺寸和销售内容先说清，前面五条有用要点，后接必要使用/养护和选购信息，不用空话凑长度；不承诺复杂HTML/图片一定前台呈现。|
|attributes|最多200字符|核实信息；多变体写明确范围，不把“像金属”当材质，不把物流估计尺寸当本体尺寸。|
|warning|仅Sí或No|模板下拉逐字一致；按当前商品填写相关安全信息。|
|warning_text|最多2000字符|Sí时一个或多个非空 `<li>提示</li>`，不包ul、不带其他标签或网址/链接；No时空字符串；B组与主组一致。|
|category|模板下拉完整原文|用mlist.py categories --search查询，选具体叶子类目，不搬固定组号对应类目。|
|gpsr_name|须适合标签排版|西语商品短名，不堆SEO，不伪造品牌；gpsr_safety为3～5条经核对西语提示，缺资料先补。|

字符串不含Excel不支持的控制字符。经验标题55～70是建议，代码硬限制55～75，以后check同步调整规则。材料不确定可说明“查看本体标签”，不用安全话术代替需要核实的规格。

搜索词参考本仓库电商经验.md：`manta borreguito / manta sofá / manta cama invierno / manta coralina`、`bolsa agua caliente`、`burlete bajo puerta`、`termo agua / termo café / botella termo / termo 1 litro / termo 500 ml`、`cama perro / cama gato`、`jersey perro / ropa perro invierno`、`tendedero radiador`、`humidificador radiador / humidificador de cerámica de radiador`、`velas perfumadas / velas decorativas / velas con frase`。这是历史联想词参考，不是每标题堆满；主词前、长尾后，正式标题正常使用重音，补词时核对当期平台联想。不知名品牌不往标题里塞。

价格按自己的成本利润定，不跟竞品；电商经验是参考，按具体商品灵活写，不把建议写成僵硬禁止条款。

## 图上文字与出图事实

overlays按组slots写01～08和variante，B可inherits主组，再覆盖02/06，共用位置reuse_from主组；variants覆盖具体变体。01/variante title为空，不叠任何新增字。辅图标题≤6词；02有3～4个points，每个text为2～3词，icon用脚本支持的图标；07有四个scenes，每个title/icon，layout=2x2或1+3；04/05/08标题各不相同。

标题说已知用途/受益，副标题说核实材质/尺寸/用途，避免没有依据的todo el año、máximo confort、抗菌或保温时长。文字少而大（全图约20词以内是设计参考）。默认模型直接设计，文字从overlays逐字照抄，出完逐字校对，不能临场补卖点。**06数字/箭头/容量/件数全部脚本画**；事实只用原商品名明确CM/L/ML，不读包裹估计尺寸；无尺寸只写内容，数量固定 `Contenido: 1 ud.` / `Contenido: N uds.`，不让模型猜。无字底图＋mlist.py overlay叠字是兜底。

content.image_description为中文外观事实摘要，锁定颜色、纹理、轮廓和结构，不是营销词；主推款摘要不覆盖其他变体附件。image_scenes07为四个中文场景描述，与overlays.scenes顺序一致；场景道具不作赠品。B未写就继承主组，商品事实不写死在程序。

## 上架前自查

1. **类目**尽量选具体、真实匹配的叶子类目。用Asignación automática de categoría须说明为何找不到合适项，提醒核对；旧批次曾因此失败，模板能填不代表平台能接受。类目专属必填属性在后台/模板核对。
2. **侵权风险**：商品/原图有品牌名、logo、卡通/IP图案、“同款”，分组阶段就问用户要不要上。标题文案不用借来的品牌词；去标题品牌不能消除实物图案风险，也不能擅自抹掉真印刷当无品牌货。无品牌按shop.brand的Sin marca，有品牌须核实来源。

GPSR标签由脚本画平面图，打印贴货；模拟效果图与实拍区分，不充当真实包装证据。制造商/负责人资料用本店shop.json确认值，不编邮箱、不套旧店身份和地址给妹妹。非电器不加WEEE或装饰性CE。标签短名/安全提示需gpsr排版检查，输出不是合规认证。
