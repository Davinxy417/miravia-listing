## 友购(10-09 实测)
- 网页版 `https://app.yollgo.com`,要登录;接口签名混淆 → 只在已登录页面里调 `ajaxFactory`,不逆向。
- **同一账号同一时间只认一个登录**(手机 App、别的浏览器会互相挤掉,接口回 401)→ fetch/yollgo-search 每次开可见 Edge 窗口,
  没登录就请用户在窗口里登录(密码已存在 skill 的 Edge 配置 `工作区/.yollgo-browser/` 里)。
- 有批发商价格含 IVA(旺达 2822)→ `suppliers.<id>.price_includes_iva`。
